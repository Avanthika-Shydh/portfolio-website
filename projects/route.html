Optimal Route Finder Using Google Maps API

Developed a route-optimization application that integrates with Google Maps APIs to fetch, parse, and evaluate multi-modal driving routes dynamically. Implemented a weighted decision-making algorithm that analyzes live traffic flows, historical congestion patterns, distance, and road conditions. The system computes and recommends the absolute optimal route, substantially reducing travel time and fuel consumption.

Technologies Used

  • Python
  • Google Maps API
  • REST APIs
  • JSON Handling
  • Data Parsing & Route Optimization
