Digital Clock and Event Scheduler Using ARM Microcontroller

Developed a complete embedded digital clock system on the NUCLEO-F401RE ARM microcontroller with an external Real-Time Clock module. Features include real-time display, alarms, countdown timer, stopwatch, and scheduled event notifications. Integrated PC connectivity using UART for monitoring and control operations.

Technologies Used

  • Embedded C
  • ARM Cortex-M4 (STM32 NUCLEO-F401RE)
  • Keil uVision IDE
  • Real-Time Clock (RTC)
  • UART Communication
  • Timer Peripherals & Interrupts
