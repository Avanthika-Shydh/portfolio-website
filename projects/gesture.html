Gesture-Based Authentication and Door Access System Using PIC Microcontroller

Implemented a secure door-access mechanism using a PIC16F877A microcontroller. The system detects hand gestures using ultrasonic sensors, activates the display, and requests a password. Upon correct authentication, the system triggers a servo motor to unlock the door. Includes buzzer alerts and LCD prompts for user guidance.

Technologies Used

  • Embedded C
  • PIC16F877A Microcontroller
  • MPLAB X & XC8 Compiler
  • Ultrasonic Sensors (HC-SR04)
  • Servo Motor Control
  • LCD Interface
