Gesture-Based Authentication and Door Access System Using PIC Microcontroller

Engineered a contactless gesture-controlled authentication and door locking system powered by a PIC16F877A microcontroller. Developed low-level drivers in Embedded C to interface ultrasonic distance sensors, a character LCD, and a piezoelectric buzzer. The system interprets distance thresholds as directional gestures to wake the interface, verify passcode input, and actuate a servo-controlled locking mechanism.

Technologies Used

  • Embedded C
  • PIC16F877A Microcontroller
  • MPLAB X & XC8 Compiler
  • Ultrasonic Sensors (HC-SR04)
  • Servo Motor Control
  • LCD Interface
