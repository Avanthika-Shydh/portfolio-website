Placement Portal Application

Developed a role-based placement management platform using Flask and SQLAlchemy, enabling seamless interaction between students, companies, and administrators. Designed a normalized relational database schema, implemented secure authentication and authorization workflows, automated application tracking, and built approval pipelines to streamline recruitment operations and ensure data integrity.

Technologies Used

  • Python
  • Flask
  • SQLAlchemy
  • SQLite
  • HTML/CSS
  • Bootstrap
  • Jinja2
  • RESTful Architecture
  • DataBase Design
  • Authentication & Authorization
